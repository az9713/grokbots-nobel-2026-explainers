# The 2026 Nobel Prizes, explained

[![View live explainers](https://img.shields.io/badge/View_live_explainers-az9713.github.io-f5a623?style=for-the-badge)](https://az9713.github.io/grokbots-nobel-2026-explainers/)

**Live landing page: https://az9713.github.io/grokbots-nobel-2026-explainers/**

Four interactive, single-page explainers of the 2026 science and economics prizes, written for technically trained readers from outside each field.

| Prize | Live page | Folder |
| --- | --- | --- |
| Physics: IceCube and the high-energy neutrino sky | [physics/](https://az9713.github.io/grokbots-nobel-2026-explainers/physics/) | [`physics/`](physics/) |
| Physiology or Medicine: switching neurons on and off with light | [medicine/](https://az9713.github.io/grokbots-nobel-2026-explainers/medicine/) | [`medicine/`](medicine/) |
| Chemistry: how chemistry learned to choose a mirror image | [chemistry/](https://az9713.github.io/grokbots-nobel-2026-explainers/chemistry/) | [`chemistry/`](chemistry/) |
| Economic Sciences: building macroeconomics from the bottom up | [economics/](https://az9713.github.io/grokbots-nobel-2026-explainers/economics/) | [`economics/`](economics/) |

Each folder has its own README, the page (`index.html`), the research dossier, the narrative script and the QA report. The chemistry folder also has the [full team transcript](https://az9713.github.io/grokbots-nobel-2026-explainers/chemistry/transcript.html).

The physics, medicine and chemistry projects were first published as separate repos. Their full commit history is kept here: each folder was imported with `git subtree`. The economics explainer was built directly in this repo.
